# Step 7 — Referral Verification (Server Round-Trip)

> Part of the [Registration Leptos Migration Plan](registration-leptos-migration.md).

**Goal:** Wire the "Verify Code" button to the `verify_referral` server function and handle success/error responses reactively. This step implements the complete request lifecycle — from user click through server round-trip to navigation or error display.

## 7.2 — Architecture Overview

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           RegisterPage Component                             │
│                                                                             │
│  ┌─────────────────┐   ┌──────────────────────────────────────────────────┐ │
│  │ referral_code   │   │  verify_action = create_action(verify_referral)  │ │
│  │ RwSignal<String>│   │                                                  │ │
│  └────────┬────────┘   │  .pending() → bool (loading state)               │ │
│           │            │  .value()   → Option<Result<ReferralVerifyResponse>>│
│           │            └──────────────────────────────────────────────────┘ │
│           │                          │                                      │
│  ┌────────▼─────────────────────────▼──────────────────────────────────────┐│
│  │                         "Verify Code" Button                            ││
│  │  - disabled when: pending() || !is_valid_uuid(referral_code)            ││
│  │  - on:click → verify_action.dispatch(referral_code.get())               ││
│  │  - shows spinner when pending()                                         ││
│  └─────────────────────────────────────────────────────────────────────────┘│
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────────┐│
│  │                         Effect: Handle Result                           ││
│  │  create_effect(move |_| {                                               ││
│  │      if let Some(Ok(response)) = verify_action.value().get() {          ││
│  │          if response.status == "success" {                              ││
│  │              current_step.set(2);           // advance to registration  ││
│  │              store_referrer_info(response.affected_rows);               ││
│  │          } else {                                                       ││
│  │              show_toast(user_friendly_msg(&response.response_code));    ││
│  │          }                                                              ││
│  │      }                                                                  ││
│  │  });                                                                    ││
│  └─────────────────────────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────────────────────┘
```

### Key Data Flow

1. **User clicks "Verify Code"** → `verify_action.dispatch()` is called
2. **Action sends HTTP POST** → `POST /api/verify_referral` (auto-generated by `#[server]`)
3. **Server function executes** → calls `verify_referral` which calls `graphql::mutate`
4. **Response returns** → `verify_action.value()` updates reactively
5. **Effect fires** → handles success (step transition) or error (toast display)

    // Handle verify_action results reactively
    Effect::new(move |_| {
        // Only run when we have a new result
        if let Some(result) = verify_action.value().get() {
            match result {
                Ok(response) => {
                    if response.status == "success" {
                        // Store referrer info for display in step 2 (optional UX enhancement)
                        if let Some(rows) = &response.affected_rows {
                            if let Some(referrer) = rows.first() {
                                verified_referrer.set(Some(referrer.clone()));
                            }
                        }

                            user_friendly_msg(&response.response_code),
                            ToastType::Success,
                        );
                        
                        // Advance to step 2
                        current_step.set(2);
                        
                        // Focus management: focus first input in step 2

                    } else {
                        // Backend returned error status
                        toast.show(
                            user_friendly_msg(&response.response_code),
                            ToastType::Error,
                        );
                    }
                }
                Err(e) => {
                    // Network error or server function error

                        ToastType::Error,
                    );
                }
            }

```rust
//! Maps backend response codes to user-friendly messages.
//!
//! These messages are shown in toasts and validation UI. They must match
//! the tone and phrasing of the existing PHP/JS application.

use std::collections::HashMap;
use once_cell::sync::Lazy;

/// Static map of response codes to user-friendly messages.
///
/// Sourced from `json/response-codes.json` in the legacy codebase.
static RESPONSE_MESSAGES: Lazy<HashMap<&'static str, &'static str>> = Lazy::new(|| {
    let mut m = HashMap::new();
    
    // Referral verification codes
    m.insert("11011", "Referral information loaded.");
    m.insert("31010", "The referral code you entered is invalid. Please check and try again.");
    m.insert("41013", "We're having trouble loading your referral information. Please try again.");
    
    // Registration codes
    m.insert("10601", "Registration successful! Please check your email to verify your account.");
    m.insert("30601", "This email is already registered. Please log in or use a different email.");
    m.insert("40601", "Registration failed due to a server error. Please try again.");
    m.insert("40602", "Registration failed: unable to generate user ID. Please try again.");
    
    // Account verification codes
    m.insert("10701", "Account verified! You can now log in.");
    m.insert("30701", "This account is already verified.");
    m.insert("40701", "Verification failed due to a server error. Please try again.");
    
    m
});

/// Default message for unknown response codes.
const DEFAULT_MESSAGE: &str = "An unexpected error occurred. Please try again.";

/// Returns a user-friendly message for the given response code.
///
/// If the code is not recognized, returns a generic error message.
///
/// # Examples
///
/// ```
/// use crate::utils::response_codes::user_friendly_msg;
///
/// assert_eq!(user_friendly_msg("11011"), "Referral information loaded.");
/// assert_eq!(user_friendly_msg("99999"), "An unexpected error occurred. Please try again.");
/// ```
pub fn user_friendly_msg(code: &str) -> &'static str {
    RESPONSE_MESSAGES.get(code).copied().unwrap_or(DEFAULT_MESSAGE)
}

// ============================================================================

// ============================================================================

    #[test]

        assert_eq!(user_friendly_msg("31010"), "The referral code you entered is invalid. Please check and try again.");
        assert_eq!(user_friendly_msg("10601"), "Registration successful! Please check your email to verify your account.");

    fn test_unknown_code_returns_default() {
        assert_eq!(user_friendly_msg("99999"), DEFAULT_MESSAGE);

## 7.6 — Implementation: Toast Component

### 7.6.1 — Create `src/components/toast.rs`

```rust
//! Toast notification component for displaying feedback messages.
//!
//! Provides a context-based API for showing toasts from anywhere in the app.

use leptos::prelude::*;
use std::time::Duration;

/// Toast notification types with corresponding styling.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum ToastType {
    Success,
    Error,
    Info,
}

impl ToastType {
    /// CSS class name for this toast type.
    pub fn class(&self) -> &'static str {
        match self {
            ToastType::Success => "toast--success",
            ToastType::Error => "toast--error",
            ToastType::Info => "toast--info",
        }
    }
}

/// A single toast message.
#[derive(Clone, Debug)]
pub struct ToastMessage {
    pub id: u32,
    pub message: String,
    pub toast_type: ToastType,
}

/// Toast context for showing notifications.
#[derive(Clone)]
pub struct ToastContext {
    toasts: RwSignal<Vec<ToastMessage>>,
    next_id: RwSignal<u32>,
}

impl ToastContext {
    /// Show a toast notification that auto-dismisses after 3 seconds.
    pub fn show(&self, message: impl Into<String>, toast_type: ToastType) {
        let id = self.next_id.get();
        self.next_id.update(|n| *n += 1);
        
        let toast = ToastMessage {
            id,
            message: message.into(),
            toast_type,
        };
        
        self.toasts.update(|t| t.push(toast));
        
        // Auto-dismiss after 3 seconds
        let toasts = self.toasts;
        set_timeout(
            move || {
                toasts.update(|t| t.retain(|toast| toast.id != id));
            },
            Duration::from_secs(3),
        );
    }
    
    /// Manually dismiss a toast by ID.
    pub fn dismiss(&self, id: u32) {
        self.toasts.update(|t| t.retain(|toast| toast.id != id));
    }
}

/// Provide toast context to the component tree.
#[component]
pub fn ToastProvider(children: Children) -> impl IntoView {
    let context = ToastContext {
        toasts: RwSignal::new(Vec::new()),
        next_id: RwSignal::new(0),
    };
    
    provide_context(context.clone());
    
    view! {
        {children()}
        <ToastContainer toasts=context.toasts dismiss=move |id| context.dismiss(id) />
    }
}

/// Get the toast context from the nearest provider.
pub fn use_toast() -> ToastContext {
    expect_context::<ToastContext>()
}

/// Container that renders all active toasts.
#[component]
fn ToastContainer(
    toasts: RwSignal<Vec<ToastMessage>>,
    dismiss: impl Fn(u32) + Copy + 'static,
) -> impl IntoView {
    view! {
        <div
            class="toast-container"
            aria-live="assertive"
            aria-atomic="true"
        >
            <For
                each=move || toasts.get()
                key=|toast| toast.id
                children=move |toast| {
                    let id = toast.id;
                    view! {
                        <div
                            class=format!("toast {}", toast.toast_type.class())
                            role="alert"
                        >
                            <span class="toast__message">{toast.message.clone()}</span>
                            <button
                                type="button"
                                class="toast__dismiss"
                                aria-label="Dismiss notification"
                                on:click=move |_| dismiss(id)
                            >
                                "×"
                            </button>
                        </div>
                    }
                }
            />
        </div>
    }
}
```

// src/pages/register.rs

use leptos::prelude::*;
use crate::api::registration::verify_referral;
use crate::models::user::{ReferralUser, ReferralVerifyResponse};
use crate::components::toast::{use_toast, ToastType};
use crate::utils::response_codes::user_friendly_msg;

/// UUID validation regex (client-side, mirrors JS)
fn is_valid_uuid(s: &str) -> bool {
    let pattern = regex::Regex::new(
        r"^[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}$"
    ).expect("UUID regex is valid");
    pattern.is_match(s)
}

#[component]
pub fn RegisterPage() -> impl IntoView {
    // =========================================================================
    // Signals
    // =========================================================================
    
    let referral_code = RwSignal::new(String::new());
    let is_referral_valid = Memo::new(move |_| is_valid_uuid(&referral_code.get()));
    let current_step = RwSignal::new(1u8);
    let verified_referrer = RwSignal::new(None::<ReferralUser>);
    
    // Toast context
    let toast = use_toast();
    
    // =========================================================================
    // URL Parameter Handling (from Step 6)
    // =========================================================================
    
    // Check for ?ref= parameter on mount
    Effect::new(move |_| {
        #[cfg(feature = "hydrate")]
        {
            if let Some(window) = web_sys::window() {
                if let Ok(search) = window.location().search() {
                    let params = web_sys::UrlSearchParams::new_with_str(&search).ok();
                    if let Some(params) = params {
                        if let Some(ref_code) = params.get("ref") {
                            referral_code.set(ref_code);
                        }
                    }
                }
            }
        }
    });
    
    // =========================================================================
    // Server Action
    // =========================================================================
    
    let verify_action = Action::new(move |code: &String| {
        let code = code.clone();
        async move { verify_referral(code).await }
    });
    
    // =========================================================================
    // Handle Action Results
    // =========================================================================
    
    Effect::new(move |_| {
        if let Some(result) = verify_action.value().get() {
            match result {
                Ok(response) => {
                    if response.status == "success" {
                        // Store referrer info
                        if let Some(rows) = &response.affected_rows {
                            if let Some(referrer) = rows.first() {
                                verified_referrer.set(Some(referrer.clone()));
                            }
                        }
                        
                        // Success feedback
                        toast.show(
                            user_friendly_msg(&response.response_code),
                            ToastType::Success,
                        );
                        
                        // Advance to step 2
                        current_step.set(2);
                    } else {
                        // Backend error
                        toast.show(
                            user_friendly_msg(&response.response_code),
                            ToastType::Error,
                        );
                    }
                }
                Err(e) => {
                    toast.show(
                        format!("Error verifying referral code: {}", e),
                        ToastType::Error,
                    );
                }
            }
        }
    });
    
    // =========================================================================
    // Computed Values
    // =========================================================================
    
    let button_disabled = Memo::new(move |_| {
        verify_action.pending().get() || !is_referral_valid.get()
    });
    
    let validation_class = Memo::new(move |_| {
        let code = referral_code.get();
        if code.is_empty() {
            ""
        } else if is_referral_valid.get() {
            "valid"
        } else {
            "notvalid"
        }
    });
    
    // =========================================================================
    // View
    // =========================================================================
    
    view! {
        <div class="container">
            // Step 1: Referral Code Entry
            <div
                id="referralStep"
                class="step"
                class:active=move || current_step.get() == 1
                aria-hidden=move || current_step.get() != 1
            >
                <h2>"Enter Your Referral Code"</h2>
                
                <form
                    id="referralForm"
                    on:submit=move |ev| {
                        ev.prevent_default();
                        if is_referral_valid.get() {
                            verify_action.dispatch(referral_code.get());
                        }
                    }
                >
                    <div
                        id="referralCodeField"
                        class="input-field"
                        class:valid=move || is_referral_valid.get() && !referral_code.get().is_empty()
                        class:notvalid=move || !is_referral_valid.get() && !referral_code.get().is_empty()
                    >
                        <label for="referralCode">"Referral Code"</label>
                        <div class="input-wrapper">
                            <span class="input-icon peer-icon-referral" aria-hidden="true"></span>
                            <input
                                type="text"
                                id="referralCode"
                                name="referralCode"
                                placeholder="xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
                                autocomplete="off"
                                prop:value=referral_code
                                on:input=move |ev| {
                                    referral_code.set(event_target_value(&ev));
                                }
                                aria-describedby="referralCodeValidation referralCodeHelp"
                                aria-invalid=move || !is_referral_valid.get() && !referral_code.get().is_empty()
                            />
                            <Show when=move || is_referral_valid.get() && !referral_code.get().is_empty()>
                                <span
                                    id="referralCodeValidIcon"
                                    class="valid-icon peer-icon-check"
                                    aria-hidden="true"
                                ></span>
                            </Show>
                        </div>
                        <span
                            id="referralCodeValidation"
                            class=move || format!("validation-message {}", validation_class.get())
                            role="alert"
                        >
                            <Show when=move || !is_referral_valid.get() && !referral_code.get().is_empty()>
